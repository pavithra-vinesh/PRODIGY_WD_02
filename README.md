# ⏱️ Professional Stopwatch Web Application

A modern, responsive, and interactive stopwatch built using **HTML**, **CSS**, and **JavaScript**. This application provides accurate time tracking with start, stop, reset, and lap recording functionality through a clean and user-friendly interface.

## 🚀 Features

* Start and stop the stopwatch
* Reset the timer to zero
* Record multiple lap times
* Responsive design for desktop and mobile devices
* Real-time time updates with millisecond precision
* Modern and professional user interface
* Scrollable lap history section

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript (ES6)

## ⚙️ Installation

1. Clone the repository:

```bash
git clone 
```

2. Navigate to the project folder:

```bash
cd stopwatch-project
```

3. Open `index.html` in your browser.

No additional dependencies or installations are required.

## 🎯 How to Use

1. Click **Start** to begin timing.
2. Click **Lap** to save the current time as a lap record.
3. Click **Stop** to pause the stopwatch.
4. Click **Reset** to clear the timer and all recorded laps.
